# andiegong.com

Personal website, built with Jekyll and hosted on GitHub Pages.

## Structure

- `index.md` — Home
- `about.md` — About
- `cv.md` — CV
- `research.md` — Research & Publications
- `_layouts/default.html` — page layout
- `assets/css/style.css` — styles

## Local development

```
bundle exec jekyll serve
```
